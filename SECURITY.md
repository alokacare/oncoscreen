# Security policy

## Scope

This repository is a local, synthetic showcase. It has no production backend, user accounts, remote database or real health data.

## Reporting

Please use GitHub private vulnerability reporting for suspected security issues instead of opening a public issue.

## Safe operation

- Do not enter real personal or health information.
- Do not deploy this package as a patient service.
- Do not add credentials to source files or commit environment files.
- Run `npm run audit:public` before every public release.
- Keep dependencies updated and review dependency alerts.

Security controls shown in the interface are illustrative and must not be interpreted as production certification.
