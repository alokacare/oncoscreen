# Intellectual-property boundary

## Included publicly

- Original showcase interface code
- Generic workflow illustrations
- Fictional sample records
- Mock request and receipt formats
- High-level architecture and safety boundaries
- Synthetic screenshots and demonstration video

## Deliberately excluded

- Controlled medical questionnaires
- Clinical mappings, weights, thresholds or prioritisation logic
- Clinical evidence dossiers and reviewer materials
- Production services, database structures and infrastructure configuration
- Private validation datasets and generation methods
- Security-sensitive operational details
- Credentials, endpoints and deployment secrets

The public demonstration does not reproduce or approximate excluded material. Its questions and workflow outcomes are generic fictional examples created solely for product demonstration.
